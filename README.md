# 🎓 Campus Connect – Student Utility App

Campus Connect is a Flutter-based student utility application designed to help students manage their academic activities through a simple and user-friendly interface.

## 🚀 Features

- **Login Page** – Student login interface.
- **Dashboard** – Overview of academic activities.
- **Attendance** – View overall and subject-wise attendance.
- **Timetable** – View daily class schedules.
- **Assignments** – View pending assignments.
- **Student Profile** – Display student information.

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design
- Visual Studio Code

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/akshithavemula/campus-connect.git
```

### 2. Navigate to the project directory

```bash
cd campus-connect
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run -d chrome
```

## 🎯 Project Objective

The objective of Campus Connect is to provide students with a single platform to access essential academic information, including attendance, class schedules, assignments, and profile details.
